# go see doc

A pretend GP booking and treatment game for a 5-year-old. Pictures first, very few words.

**To play:** double-click `index.html`. No install or internet needed.

- **book**: type a name, pick a feeling, pick a time.
- **go**: pick a patient from the waiting list, choose a treatment, and watch them get better.

Bookings are saved in the browser. To clear them, clear the site data in the browser.
